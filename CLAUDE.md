# Wskazówki dla asystenta

Wszystkie zasady tego projektu są w **[README.md](README.md)**. Przeczytaj go
w całości, zanim wprowadzisz pierwszą zmianę.

Nie powielaj tutaj tamtej treści — README jest jedynym źródłem prawdy.
Jeśli ustalenie z Arturem zmienia któryś z zapisów, popraw README
w tym samym commicie, w którym wprowadzasz zmianę w kodzie.

Punkty, które najczęściej bywają łamane przez nieuwagę:

1. **Żadne dane nie opuszczają przeglądarki** (README, punkt 2.1). Zero
   analityki, zero wysyłki wyników. Wyniki testów psychologicznych to
   potencjalnie dane o zdrowiu z art. 9 RODO.
2. **Repozytorium jest publiczne** (punkt 2.3). Nic poufnego, również
   w historii Gita.
3. **Treść testów tylko w plikach JSON** (punkt 3.1). Silnik nie zawiera
   treści żadnego testu.
4. **Skala odpowiedzi to pełnowymiarowe wiersze z nazwą każdego stopnia**
   (punkt 3.4). Nie wracaj do siatki małych cyfr.
5. **Czerwień i pomarańcz są wykluczone z palety** (punkt 3.3).
6. **Dolna granica zgodności to Chrome 109** (punkt 3.7).
7. **Sprawdź zmianę w przeglądarce przed commitem** (punkt 7).
